## Rules

- Write numbers in international digits in both languages: 1857, not १८५७.
- Write dates as "26 January 1950" in English and "26 जनवरी 1950" in Hindi. Write reigns as "1433–1468".
- A ruler with a number is "Maharana Kumbha", "Rao Jodha", "Sawai Jai Singh II". Use Roman numerals.
- On first mention in a chapter, give a place's other names in brackets, for example "Bairath (Viratnagar)".
