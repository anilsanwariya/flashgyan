# Knowledge files for the "Rajasthan Atlas — Subject Notes" Claude Project

Upload these files to the project's knowledge. The setup itself (goals, instructions to paste, prompts, checklist) is in `../atlas-extraction-project.md`.

| File | What it is |
| --- | --- |
| `01-Syllabus-Rajasthan-History.md` | The 14 chapters of Rajasthan History and their numbered topics, in English and Hindi: the order to work in |
| `02-District-names.md` | The 7 divisions and 41 districts in English and Hindi, the 2023 and 2024 changes, and old spellings to replace |
| `03-Spellings.md` | House spellings in English and Hindi, and rules for numbers and dates |
| `04-Chapter-template.en.md` | The exact shape of an English chapter file, with the "Place:" block |
| `04-Chapter-template.hi.md` | The same in Hindi (the structural markers stay in English) |

When you move on to another subject, add its syllabus outline in the same shape: `01-Syllabus-Rajasthan-Art-and-Culture.md`, and so on.
